Tandem — art overview

All 189 graphics the game draws, at their original pixel size. Click an image to download it. Every file is also in the art/sprites folder, with art/manifest.json describing each one.

For upscaling
  • Keep the transparent background, the same orientation (enemies and bosses face left, the player ship faces right) and the same aspect ratio.
  • Keep the file name and save the result in art/upscaled/ with the same folder structure, so each file can be matched to its sprite.
  • Floor textures must stay seamless (the edges tile).
  • In the game every coloured pixel becomes a small 3D block, so clear shapes and strong outlines work best.
